# Brand Product Comparison Tool 🚀 
A real-time web application that compares products from two brands using Google Shopping data. 

## 🔥 Features 
* Compare products between two brands
* Live prices from Google Shopping
* Ratings and reviews
* Store links
* Data analytics charts
* User-friendly Streamlit UI


## 🛠️ Technologies Used 
* Python
* Streamlit
* Pandas
* FastMCP
* SerpAPI
  
## 📂 Files 
* compareprompt.py → Frontend UI
* compareserver.py → Backend server logic
  
## ▶️ Run Locally

pip install -r req.txt

streamlit run compareprompt.py
